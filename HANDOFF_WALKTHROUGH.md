## 0. Operating rule: Codex gpt-6-astra does the model work

The owner's standing instruction (18 September): every model task on this project — review rounds, editing passes, logo and packaging design, research, redesigns — runs on **Codex CLI with `gpt-6-astra`**. Claude's job is orchestration: write prompts and schemas, launch `codex exec` detached, run the deterministic gate, verify outputs against the repository, commit. Do not spawn Claude subagent workflows for judging or editing (they died twice on the session limit and the owner asked for Codex). The memory file `operate-with-codex.md` records this.

Codex CLI facts learned the hard way: `~/.npm-global/bin/codex` (0.154.0, ChatGPT login). Root flags such as `--search` go BEFORE `exec` (`codex --search exec …`). `--approve-for-me` cannot be combined with `--sandbox`; use `--approve-for-me` only for runs that must edit repository files. `-s workspace-write -C <dir>` makes only that directory (and /tmp) writable, so a run with cwd in a scratch folder cannot touch the repo (how the review round keeps the page frozen). `--output-schema <file>` enforces JSON on the final message; schemas must be strict (every property required, `additionalProperties: false`, see `tools/walkthrough/codex_round/schemas/`). Always close stdin (`< /dev/null`) or the run waits forever. Codex's sandbox cannot launch Chrome on this Mac (mach port permission denied): render screenshots yourself with `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --user-data-dir=<scratch>/chrome --window-size=1440,1800 --virtual-time-budget=2000 --screenshot=<out.png> "file://<page>#N"` (about 15 s each; run ten of them in the background). `qlmanage -t -s 1024 -o <dir> <svg>` renders SVG but XML has no HTML entities: replace `&middot;` with `·` first. Codex refuses to overwrite an existing asset file name (it creates a sibling). The `timeout` command does not exist on macOS.

## 2. Tools (all under `tools/walkthrough/`)

- `checks.py [--file <page>]`: the deterministic gate (exit 0 = green): verbatim clippings and cited anchors against `fixtures/northlight_01/`, zero external resources, ≤10 sheets, ids and folios and `CH` array in sync, scripts parse, tags balanced, titles ≤24 words, takeaways ≤20, ≤650 visible words per sheet (750 on 09), X3 (no budget total as a fact; entities decoded; `<s>`/`mark.flag` text exempt), key-visual palette and clear space and no opacity, mock-up label inside the 9:16 crop, three top-level decisions, no empty evidence blocks. Never relax a rule to pass it.
- `build.py [--src <page> --out <file>]`: artifact variant (strips doctype/html/head/body; repo links become spans).
- `codex_round.py --round N [--page <file>] [--args roundN_args.json]`: the review round on Codex: two auditors (repository fidelity; rendered UX), two skeptics per claimed hard failure, four audience tasks, three scoring personas, deterministic verdict (stable = no hard failures, tasks pass, no aspect down ≥0.5 vs `prev`, all agents present), an editor brief. Write `roundN_args.json` from the previous `result.json` (`prev.averages`, `prevHard`, `mustKeep` from the brief) and fill `hash` with `shasum -a 256`. About 20 minutes at concurrency 5. Do not edit the page while a round runs.
- Editing passes: a Codex run with `--approve-for-me` and a prompt like `codex_edit_r10_prompt.md`: apply the brief item by item, verify every factual item against the code or document it concerns before applying, keep the `mustKeep` list intact, gate green, report per item. Apply hard failures and precision items to the current page; leave layout and taste items to the redesign.
- `codex_redesign.py`: research (`codex --search exec`) then build; outputs under `redesign/`. To propagate later page edits into v2: `cp WALKTHROUGH.html tools/walkthrough/redesign/source_snapshot.html && python3 tools/walkthrough/redesign/build_v2.py && python3 tools/walkthrough/checks.py --file tools/walkthrough/redesign/WALKTHROUGH_v2.html` (confirm the transform still applies cleanly; it was written against the round-9 markup).
- `swap_kv.py --src <svg>`, `embed_packaging.py --src <png> [--caption --alt]`, `compare_cans.py`, `compare_logos.py`, `edit_r7.py`, `edit_r8.py` (Claude-era passes, kept for the record), `backups/` (page before every pass), `round8_args.json`, `round10_args.json`, Codex prompts and reports (`codex_*_prompt.md`, `codex_*.md`).
